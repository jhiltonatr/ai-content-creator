## Basic Story CRUD outline
Goal: 
Enables a user to start a new story and manage creation, edit and deletion of the story

## Requirements
Note: the content edition page differs by the `Story Type` selected


### Create Story
The user should be able to create a new story by providing the following
```
Required information:
- id (autogenerated numeric value)
- Story title
- Story Type
- Genre
- Language

Optional information:
- Description
- tags
```
After creating the story successfully it should navigate to the content edit page for the story, carrying the id generated

Note: the content edition page differs by the `Story Type` selected

### Edit Story
The user should be able to edit a new story by providing the following
```
Required information:
- id (not editable)
- Story title
- Story Type (When edited confirm that the content will be lost and let the user decide to continue)
- Genre
- Language

Optional information:
- Description
- tags
```


### Delete Story
The user should be able to delete a story
A confirmation dialog should be displayed 

### Stories List
Lists all stories created with basic information
```
Required information:
- id (hidden)
- Story title
- Story Type (create a badge like label to keep differentiation simpler)
- Genre
- Language (a country flag system would be best, focus on English and Japanese for now)
```
