# Plan: Basic Story CRUD

Spec: `specs/basic-story-crud.md`

Enable creating, editing (metadata), deleting, and listing stories.

## Domain decisions

- `Story` gains: `storyType`, `genre`, `language`, `description`, `tags`. `content` is kept (used by the separate story-content-edit spec).
- `StoryType` enum: `NOVEL` for now (user decision — additional types will be added via separate specs; kept extensible).
- `Language` enum: `ENGLISH`, `JAPANESE` (spec: flags, focus on English and Japanese for now).
- `genre`/`tags` are free-text; `tags` sent as a JSON string array.
- `id` stays server-generated (numeric). Metadata edits keep `createdAt`/`content` client-supplied back to the server (in-memory storage).

## API contract

- `GET /api/stories` — list all (sorted by id)
- `GET /api/stories/{id}` — single story (404 if missing)
- `POST /api/stories` — create, id autogenerated (201)
- `PUT /api/stories/{id}` — overwrite metadata/content (404 if missing)
- `DELETE /api/stories/{id}` — delete (204, 404 if missing)
