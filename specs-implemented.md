# Implemented Specs

- [x] Basic Story CRUD (`specs/basic-story-crud.md`) — create/edit/delete/list stories with title, story type, genre, language, description, and tags; creation navigates to the story content editor. See `plans/basic-story-crud.md`.
- [x] Story Content Edit (`specs/story-content-edit.md`) — per-story-type badge and content editor (NOVEL: Story -> Books -> Chapters). Nested CRUD REST API, cascade deletes, book re-sorting, and a UI with a content page (book accordion + book-title search + re-order) and a per-book page (rename book, chapter accordion with read/edit/delete). See `plans/story-content-edit.md`.
- [x] Editor Component (`specs/editor-component.md`, `specs/editor-components/text-color.md`) — Markdown editor module for chapter bodies with raw/preview tabs, a selection-aware formatting toolbar (bold, italic, strikethrough, code, links, headings, quotes, lists, code blocks, horizontal rule), and a text-color picker; preview rendered via `marked`. See `plans/editor-component.md`.
